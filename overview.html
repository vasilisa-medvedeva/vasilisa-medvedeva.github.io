Pyroblast UI

The mobile design system of Pyroblast — a messenger for gamers — rebuilt live in code. Every component on these pages is real HTML driven by the same tokens it documents: what you inspect is what the system is.

Pyroblast had a design system per platform in Figma — desktop, iOS and Android. This library is the mobile one.

How the library is organized

StylesFoundations — typography, color, spacing, radius and elevation, defined as tokens IconsThe icon set, grouped by where it's used: tab bar, chats, menus, general AtomsThe smallest parts — buttons, toggles, avatars, chips, counters MoleculesAtoms combined into working units — cells, fields, bars, messages OrganismsComplete interface blocks — profile cards, dialogs, the meet bar
Avataratom → CellContactmolecule → CardProfileorganism One real chain: the same Avatar atom serves a contact cell, which serves the profile card — fix the atom once, and every level inherits it.

How to read a token

--colorgroup primaryfamily transparent-60step
  • primary is the content color; constant stays fixed regardless of what it sits on. The split was groundwork for theming — the product closed before a dark theme was needed.
  • Every family — including brand and signal colors — runs the same alpha scale, so hierarchy comes from steps of one color, not from new colors.
  • Text tokens mirror Figma names: the style Label/Medium · 12/14 becomes --text-label-medium-*.
